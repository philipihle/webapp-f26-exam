# SubTask 1 – Study Room Booking Tool (ASP.NET 10.0 MVC)

## Running the Application

From the `SubTask1` folder:

```powershell
dotnet run
```

To run the backend unit tests from the repository root:

```powershell
dotnet test SubTask1.Tests
```
